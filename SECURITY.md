# Security

This repository contains documentation and templates only. It has no software service or executable releases to patch; unsafe guidance can still warrant a sensitive report.

## Do not post sensitive material publicly

Never include secrets, credentials, API keys, personal or private data, vulnerabilities, exploit details, or details of an unfixed vulnerability in a public issue, pull request, or discussion.

## Intended private reporting route — not live

Elijah plans to enable GitHub private vulnerability reporting after the repository exists. It is not yet enabled or verified. Do not treat the planned URL below as an operational reporting channel. Use the route only after enablement AND verification are explicitly confirmed here.

Planned repository: https://github.com/REA-Research-Labs-Inc/agent-safety-review-kit
Planned reporting form: https://github.com/REA-Research-Labs-Inc/agent-safety-review-kit/security/advisories/new

Once enabled and verified, use the repository's Security > Advisories > Report a vulnerability form for sensitive flaws in this kit's guidance. Until then, do not send sensitive reports through public channels; no alternative private contact is being offered here. Do not submit real secrets or private data even in a reproduction; use sanitized examples.

Private reports are accessible only to authorized GitHub roles and explicitly authorized advisory collaborators under GitHub's access controls. Social Media's public issue-intake role does not itself grant access to private reports. Private-report access, notifications, and monitoring remain unverified. No monitoring schedule or response SLA is established.

## Non-sensitive documentation feedback

Social Media handles issue intake and triage, coordinating with the CTO on technical and security matters. Response times are not guaranteed. Use public issues only for non-sensitive documentation feedback; do not include secrets, private data, vulnerabilities or exploit details.

This kit makes no security guarantee and does not certify any system. See the [README](README.md#limitations).
